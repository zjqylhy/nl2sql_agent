## 真实模型结果与限制

- 首轮授权 20 次，实际 20 次：6 个场景符合预期，14 次 HTTP 429；测试器当时没有在首次 429 后停止，原始失败保留。
- 追加授权最多 14 次，仅补测原限流题，至少间隔 20 秒；实际发送 5 次：3 个场景符合预期，1 次 HTTP 200 但 `finish_reason=length` 且无可见内容，随后 1 次 HTTP 429（Retry-After=1）即停止，剩余 9 次未用。
- 合并两个批次，共 25 次出站请求；20 个不同场景中，9 个取得预期结果，1 个仍被截断，10 个仍受请求限制而未完成验证。未观察到这 9 个已完成场景的条件不匹配，不能据此报告 20 题全部通过或模型成功率 100%。
- 截断出现在 `active_devices`；模型最大输出仍保持 2048，未扩大预算或自动重试。截图相近的两条多轮真实题仍受限；对应后端恢复链路通过模拟模型与真实 PostgreSQL 检查，不能替代真实供应商验收。
- 此轮真实测试只生成并验证计划，未执行 SQL、未创建生产任务、未保存隐藏推理或凭证。完整审计报告位于服务器隔离验证目录；仓库仅记录去敏汇总。

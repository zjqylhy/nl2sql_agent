# 推送消息树实现与验证

## 存储契约

`push_threads` 保存归属、角色/数据绑定、活动任务、当前分支和游标；`push_messages` 以不可变父指针连接，`seq` 仅用于稳定展示。`push_branches` 保存分支头和分叉点。回退只移动游标，从旧位置继续会创建另一分支，旧节点和结果不被覆盖。

`push_revisions` 将回答节点关联到完整计划、展示配置、父回答版本及结果任务。`push_summaries` 保存祖先路径前缀的消息 ID 和摘要原文。数据库触发器禁止修改/删除消息、版本和摘要，并要求父消息是同会话中已存在的节点，避免跨会话连接和环。

`push_model_calls` 保存实际有界请求、规则版本、模型可见响应原文、校验后的动作、供应商用量及调用状态。未知调用不会自动重发。工具请求/结果作为配对树节点保存，完整数据引用不可变的已完成任务结果。现有单次查询接入会话时导入已有问题、已保存追问/回答和结果；此前未存下的供应商原始响应不会补造。

## 上下文与交互

仅当前祖先链进入模型上下文，禁止引用其他分支的基准回答；明确引用祖先旧版本时可读取其原文或完整计划。修改条件以完整旧计划为基础应用部分字段更新，重新执行授权查询；调整表格/卡片、简洁/详细和口径解释复用证据，不额外执行 SQL，业务数值仍由代码渲染。

预算允许时使用完整祖先消息；必要上下文保留当前完整计划、本轮指令、补充和权限规则。输入沿用 UTF-8 字节保守上界 6000（包含封装余量），输出另设上限；历史放不下时按祖先前缀生成带来源摘要，原文不删除。摘要与决策共用每个查询任务最多 4 次模型调用、30000 预留 Token 上界，未知用量保留为未知。必要内容或最近消息仍放不下则拒绝发送并提示用户处理。会话最多 30 条用户消息，分支共享该上限。

查询执行或等待补充时不能切换游标；停止后迟到执行者不能发布新消息。幂等请求、会话版本与数据库锁防止双击和多标签页覆盖。指标及分子分母权限撤销、角色或数据源变化后拒绝读取和续接。

## 已完成验证

- 本地全量回归：396 passed、零跳过、169.42 秒，包含首批 12 项消息树测试。
- 前端 TypeScript/Vite 构建通过。
- 独立数据库与模拟模型实际界面完成首版查询、后续筛选、回退、自动分叉及刷新恢复。7月全部厂商发送量3720，只看华为741；从首版改查9月得到全部厂商3600，保留原华为分支。
- 补充的祖先原文取回、旧版计划继承和并发提交验证另行记录；服务器隔离回归与发布结果在完成后追加。

验证未向真实模型发送问题，不代表真实模型理解准确率；回答调整目前覆盖受限展示配置及既有口径解释，不能任意改写数值或生成业务归因。

## 必须保留的兼容逻辑

v1 指标目录参与现有会话和报告的绑定摘要，不能为了精简而直接改写目录中的月份表达式。保留发布描述，由 `postgres_sql` 在目录校验与 SQL 编译时统一渲染为 PG；它不提供 MySQL 数据源或执行能力。

使用线上现有三个角色的可信映射，只计算元数据，与清理版本在无网络容器中的结果比较：查询绑定、分析绑定及目录摘要全部相同。该检查未访问生产数据库。活动任务仍受原代码摘要围栏限制，部署前需收敛未完成任务；没有为了兼容放宽恢复规则。

# 经营分析 A/B/C 服务器预实验

日期：2026-10-17。承接已确认的独立评测规格，用户要求继续，并指定部署和测试均在服务器执行。本批先修正评测记录，再运行开发分区预实验；不修改生产 Agent、提示词、任务集标注或模型网关。

## 范围与解释边界

- A：原单步问数，返回多行不由判分器代做合计或跨期比较；Top1 无附加核查可完整完成时正常计分。
- B：当前受限 ReAct 图，由模型逐步选择工具。
- C：相同模型解析规格，此后由固定依赖计划选择工具。
- 三组使用相同提交、夹具、只读授权、模型别名和计价，独立 API/Worker 与临时数据库。评测 PG 使用单独容器，不在生产 PG 建立或删除夹具。
- 题集仍为 `draft`，不代替人工复核。选开发分区完整意图组 `01/13/19/29/33/37`，各含两种表达，共 12 题：金额下降、Top1、复杂 TopN、无数据、补充、范围外。每组重复一次，三组共 36 个任务。
- 在调用前确定题目和判分规则。失败保持在分母，不因真实结果不佳调整题目、标签或提示词；此轮执行后这些题视为已曝光开发样本。

## 本批评测修正

1. `--max-model-calls` 限制整项研究，不能随组或夹具重置。每个隔离栈只领取剩余额度；停止所有子进程后从 PG 原子计数结算，再删除本次随机数据库。读数失败中止研究，不启动下一栈。额度耗尽的后续题标记未执行并保留分母。
2. 逐题原子保存报告，记录实际执行树摘要、已提交版本、数据/依赖摘要、实际规格、受限工具参数、确定性报告、失败码和 HTTP 状态。保留合成数据的判分证据，不保存供应商原始响应或凭据。只读源码 archive 必须声明完整提交标识；部署者核对上传 archive 摘要。此身份不等于生产镜像发布门禁。
3. “范围外/无数据”不能把 503、未知调用、截断、预算耗尽或任意 failed 判为正确。范围外需明确请求澄清不支持的目标/表达且不查询；无数据需正确规格与查询范围、实际负面数据证据。保守判分不能证明自然语言拒绝说明的全部质量。
4. TopN 查询必须匹配已确认 N 和 GMV 降序；全量候选查询可留空 TopN。参数错误与冗余分开计数；`extra_calls` 仅计已命中缓存的重复工具调用，是可观察下界，另报高于标注最少工具数的次数，不把两者等同为精确多余调用数。

## 本轮约束

整项预实验最多 **120 次供应商调用**，不是每组 120 次；每题端到端等待上限 360 秒，保留原任务自身的调用/SQL/Token/活跃时长约束。使用用户已允许的 `TEST_UNIT`，不是实际货币。B/C 输出上限 4096、单次截止 45 秒、单任务 50000 Token、模型调用间隔 20 秒，与服务器当前配置一致。A 保留原解析传输配置（计划输出上限和 20 秒分段超时单独记录），不把各组传输实现宣称为相同。

各组每题完成后均等待 20 秒，避免连续接纳触发网关速率限制；该题间等待不计入任务延迟，任务内部的持久间隔计入端到端延迟。该条件与真实并发流量不同，不能把预实验 P95 当作线上负载性能。

研究顺序 A/B/C；这是流程与失败记录预实验，顺序负载和小样本会影响结果，不作显著性或泛化结论。正式对照前需要人工复核、扩充未曝光意图组、重复运行并平衡顺序，使用已确认实际价格后才可比较真实费用。

服务器先验证新增 scorer/全局额度跨栈结算、隔离清理及原评测回归；通过并提交后运行真实模型。输出完整任务成功率、行为符合率、工具参数正确率、重复调用下界、模型/SQL 次数、端到端 P50/P95、已知 Token 和测试预算、未知用量。API 观测模块只用于隔离测试，生产 8088 和生产配置保持当前版本。

服务器验证：完整回归 **398 passed, 12 skipped，107.84 秒**；最终增加判分证据和统计字段后，scorer 专项 **9 passed，0.36 秒**。12 项为旧 MySQL 路径。此前测试用临时内存盘不足、打包遗漏旧迁移夹具及新增测试缺少配置的问题均已修正后重跑，原始失败日志保留在服务器，不计为真实模型实验。

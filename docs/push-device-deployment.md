# 推送与设备分析私有发布

## 发布规格

用户于 2026-10-18 授权提交 PR 并部署服务器。本次将已验证的推送代码发布到现有私有 ECS；PR 保持待审，不自动合并。

- 发布仅使用 Git 提交归档；原有 ruleset 工作区修改不纳入发布。
- 沿用现有 Compose 项目名、网络、PostgreSQL 容器及数据卷，避免根目录默认项目名变化创建第二套存储。
- 原 alpha 订单数据映射、账号和历史任务保留。推送模拟数据使用独立不可变 schema，新租户 push 的 admin 使用现有管理员的密码验证值，只授权推送指标。
- 推送映射绑定数据摘要、起止范围、截止时刻和模拟标识，查询角色仅可读四个授权视图；数据在服务器生成，不导出生产数据。
- 先完成候选构建及服务器隔离 PostgreSQL 回归，再排空任务、停止 API/Worker、备份并切换。保留旧镜像、环境配置与源码入口，失败恢复旧服务。
- 验证健康、登录、结构化推送/设备查询、固定流程完整报告、历史订单查询、SSE、版本标签及备份。真实模型冒烟与模拟协议验证分别记录，不能作为准确率评测。
- 部署后保存脱敏版本、测试和备份证据；凭据与完整数据库备份留在受限服务器目录。

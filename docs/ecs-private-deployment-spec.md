模型网关为 47.113.231.252，已验证既有 SSH 连接和其回环 TLS 服务 127.0.0.1:8443。本轮已创建双数据库、专用模型隧道和业务容器，六个常驻容器均健康。

## 技术方案

### 数据与运行权限

使用独立 deploy/compose.private.yaml，运行 PostgreSQL 17、MySQL 8.4、API、agent、web 和模型隧道容器。复用现有业务镜像，不改业务问数语义。

双数据库使用独立 Docker 持久化 volume。首次初始化只允许空数据目录，不复制开发机数据库，不覆盖已有业务数据。导入现有官方 Olist CSV，核对 99,441 条订单事实与分析基准 2018-08-31。

PostgreSQL 管理/迁移账号与 API 运行账号分离：运行账号只获业务表 DML，不具 DDL 或迁移记录表权限。MySQL 独立只读账号仅能读取 metric_orders 视图，不能读底表或写入。

数据库不发布宿主端口，仅在项目私有 Docker 网络通信。单机内网阶段复用本地数据库连接方式；后续跨主机或迁移 RDS 时必须恢复 CA 和主机名验证。

### 2 核小内存约束

初始硬内存限制：MySQL 640 MiB、PostgreSQL 192 MiB、agent 256 MiB、API 128 MiB、web 64 MiB、模型隧道 32 MiB，常驻容器合计 1312 MiB。迁移为一次性 128 MiB；初始化数据时暂不启动其他应用，避免峰值叠加。

MySQL 收紧 buffer pool、连接数、临时表和缓存，关闭 performance_schema；PostgreSQL 收紧 shared_buffers、连接数与 work_mem。应用不依赖 swap 提供常态容量。镜像在本机构建并验证后通过 SSH 传输，避免 ECS 构建内存峰值。

首阶段适用个人/小规模私有使用。检查启动、导入、单次和小并发查询的全机内存、OOM、重启次数与延迟；实测不稳定时调整配置或明确升级需求，不宣称达到原 50 活跃任务目标。

### 私有应用入口

web 仅绑定 ECS 127.0.0.1:8088。本机转发 127.0.0.1:8088 到云端同端口，访问 http://localhost:8088。origin 和 Cookie 匹配 HTTP 回环访问，传输加密由 SSH 提供。

不开放公网 HTTP 或数据库端口。备案完成后再部署宿主 Nginx、证书、HTTPS origin 和 Secure Cookie，并重新验证登录和 SSE。

### 云端模型隧道

ECS 生成专用 SSH 密钥，私钥仅存云端受限目录。网关建立专用转发身份，限制来源为应用 ECS，只允许本地转发到 127.0.0.1:8443，禁止交互 shell、PTY 和反向转发。不将既有网关管理私钥复制到应用 ECS。

隧道容器仅连接项目网络，无宿主端口映射，设置失败退出、保活与自动重启。agent 经容器 DNS 连接隧道，沿用证书 TLS 主机名和公开 CA，使用已有 LLM_CONNECT_HOST / LLM_CA_FILE 能力；不关闭模型 TLS 验证，不依赖 Windows 常驻隧道。

### 发布、备份与恢复

镜像使用 commit 标识，记录实际 image ID、传输包 SHA256，不使用付费镜像仓库。单独迁移，授权运行账号，导入数据和初始化管理员，然后按数据库/隧道 → agent → API → web 的健康依赖启动。

每日分别备份双数据库，写入权限 0700 的宿主目录，按备份 UTC 时间保留最近 7 天的全部完整备份，失败保留此前有效备份。启用 systemd 定时任务；首次备份下载本机，在独立临时数据库恢复验证。记录数据、账号和配置恢复步骤，不备份 SSH 私钥。

同盘备份不能抵抗 ECS/云盘丢失；首次本机副本之外，持续异地备份仍需用户指定存储目标及费用。本阶段不宣称具备云灾备或高可用。

私有部署以实际镜像、真实 Olist、登录、规则/模型问数、SSE、最小权限、备份恢复和重启恢复验收。原 [正式 RDS/HTTPS 发布门禁](aliyun-release-spec.md) 保留，本阶段不冒充其三轮正式镜像门禁已通过。

## 拟实施技术方案

### 数据库与镜像

双 RDS 选择 `cn-heyuan`，与 ECS 使用同一 VPC；实际规格、引擎版本、存储和含优惠价格须在购买页核对并人工确认后创建。优先 PostgreSQL 17、MySQL 8.4；若所选规格不支持这些版本，先验证兼容性并确认方案变更。

保留 PostgreSQL 迁移/运行身份分离、MySQL 受限视图只读身份、CA 和主机名验证。数据库不申请公网地址。初始化空数据库、Olist 数据和管理员账号后，验证最小权限和实际结果。

镜像使用完整 commit 与不可变摘要，发布前保留真实镜像验收证据。ACR 费用也计入明确后的预算范围；不能用源码测试报告替代已确认规格中的镜像门禁。现有云发布步骤见 [发布规格](aliyun-release-spec.md) 和 [运维手册](aliyun-operations.md)。

### 首阶段应用访问

web 仅绑定 ECS `127.0.0.1:8088`。本机通过 `ssh -N -L 127.0.0.1:8088:127.0.0.1:8088 root@8.155.128.79` 建立隧道，并使用 `http://localhost:8088` 访问。启动命令实际需要指定用户私钥；文档命令只说明端口关系。

此阶段浏览器 origin 为 `http://localhost:8088`，HTTP 流量通过 SSH 加密传输。需要单独的私有部署配置，将 `PUBLIC_ORIGIN` 和 Cookie 设置与实际访问入口匹配；原正式模板的 HTTPS 校验不能冒充已通过。该配置仅用于回环入口，不向公网开放 HTTP、数据库、API 或 agent 端口。

备案完成后配置域名证书和宿主 Nginx，切换 HTTPS origin 与 Secure Cookie，再验证 HTTPS、同源请求、登录和 SSE。首阶段不安装默认公网 HTTP 网站。

### 云端模型隧道

拟在应用 ECS 上生成专用 SSH 密钥，私钥仅存放在 ECS 的受限目录；网关使用专用转发身份，只允许从应用 ECS 转发至 `127.0.0.1:8443`。不将本机已有网关管理私钥复制到应用 ECS。

隧道由 systemd 管理，设置连接失败退出、保活和失败重启。监听地址仅供云端容器访问，不绑定公网地址；实际 Docker 地址在配置时核对，避免硬编码错误网段。

沿用网关证书中的 TLS 主机名和公开 CA，使用 agent 已有的 `LLM_CONNECT_HOST` / `LLM_CA_FILE` 能力连接隧道。云配置需补齐相应环境变量与只读 CA 挂载，并重新生成对应配置的镜像验收证据。不关闭证书验证，也不依赖本机 Windows 隧道。
